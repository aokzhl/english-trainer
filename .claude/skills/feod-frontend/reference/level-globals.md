# Уровень Globals — доступное без импорта

## Назначение

Специальный **опциональный** уровень для сущностей, доступных глобально во
всём проекте **без импорта**. Отвечает на вопрос «откуда это взялось?» для
кода, работающего без явных импортов.

## Что здесь хранится

- **Глобальные типы** — `env.d.ts`, доступные без импорта определения;
- **Shims** — расширения типов и функциональности сторонних библиотек
  (например, расширение `RouteMeta` роутера);
- **Полифиллы** — поддержка устаревших браузеров/платформ;
- **Манки-патчи** — временные исправления библиотек (минимизировать!);
- **Расширения встроенных типов** — `Window`, `Array` и т.п.

## Пример структуры

```
globals/
├── env.d.ts
├── window.d.ts
├── router.d.ts          # расширение типов TanStack Router
└── array.polyfill.ts
```

## Правила

1. **Ничего не импортирует и никем не импортируется.** Подключение — на уровне
   конфига сборщика/tsconfig или index.html, не в коде приложения.
   Если импорт неизбежен — определить alias и использовать только в конфигах.
2. **НЕ место для повседневной логики.** «Это не место для UI-библиотеки или
   чего-то подобного!» Компоненты, утилиты, хуки → common; бизнес-логика → modules.
3. Если сущность требует импорта — она НЕ принадлежит globals.

## Globals vs Common

| Аспект | Globals | Common |
|--------|---------|--------|
| Доступность | без импорта | требуется импорт |
| Содержимое | типы, полифиллы, shims | компоненты, утилиты, логика |
| Загрузка | при старте приложения | по требованию |
| Переиспользуемая логика | НЕТ | ДА |

## Лучшие практики

1. **Минимизируй использование** — только действительно необходимые случаи;
   как можно меньше файлов, максимально изолированная логика.
2. **Документируй каждое расширение типов**: причину, добавленные поля,
   назначение — это критично для понимания кода в будущем.
3. **Расширяй обоснованно** — только типы, изначально предусмотренные
   библиотекой для расширения; избегай хаков без крайней необходимости.
4. **Не заводи глобальные переменные** без необходимости — для переиспользуемых
   значений есть common.
