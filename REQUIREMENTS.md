# WordForge — платформа курсов английского

## Документ требований (v2.0 — на согласовании)

> История: v1.x описывал WordForge как тренажёр слов (SRS-карточки). В v2.0
> продукт разворачивается в **платформу курсов**: слова становятся одним из
> курсов, рядом появляется **курс по грамматике**, а ключевая новая ценность —
> **проверка усвоения через ИИ**. Дизайн-обоснование:
> `docs/superpowers/specs/2026-07-02-course-platform-design.md`.

## 1. Цель и аудитория

**Цель:** помочь пользователю системно учить английский через **курсы** —
короткие ежедневные занятия (3–5 минут) с тренажёрами, прогрессом и проверкой
усвоения. На старте два курса: **словарь** («3000 слов для Intermediate») и
**грамматика** («Grammar Is All You Need 2.0»).

**Пользователь:** русскоязычный, изучает английский самостоятельно, уровень ~A2
и выше. Основная боль — материал плохо запоминается и быстро забывается,
непонятно, усвоена ли тема на самом деле.

**Курсы бесплатные.** Оплаты и биллинга в системе нет.

**Ключевая метрика успеха:** пользователь возвращается ежедневно и стабильно
проходит материал — переводит слова в статус «выучено» и сдаёт темы грамматики.

## 2. Модель платформы

### 2.1. Курсы

- Страница **«Курсы»** — витрина: список доступных курсов с прогрессом
  пользователя. Пользователь **записывается** на курс (enrollment) и заходит в
  него.
- Каждый курс имеет **тип**, определяющий внутреннюю механику:
  - **vocabulary** — набор карточек, интервальные повторения (система Лейтнера).
  - **grammar** — последовательность уроков: теория → упражнения → ИИ-экзамен.
- Общая оболочка для всех курсов: запись, прогресс по курсу, **стрик** 🔥,
  **дашборд** со сводкой по всем курсам.

### 2.2. Аккаунты и прогресс

- Регистрация и вход: **email + пароль** (bcrypt), сессия — access-JWT +
  stateful refresh-токен (реализовано). *Без изменений относительно v1.*
- Прогресс, свои карточки и стрик привязаны к аккаунту → доступны с любого
  устройства.
- **Стрик** 🔥 — дни занятий подряд (засчитывается любое учебное действие:
  повторение карточки, выполнение упражнения, сдача урока).
- Прогресс считается отдельно по каждому курсу; дашборд агрегирует.

## 3. Курс-словарь (vocabulary)

### 3.1. Контент

Встроенный контент — общий seed, доступен всем. Источник MVP: «3000 слов для
Intermediate» (`docs/source/words-3000-intermediate.md`) — ~3000 слов,
сгруппированы по темам (12 недель → ~60 тем → подтемы).

**Структура карточки:**
- Слово/фраза на английском, перевод на русский
- Уровень CEFR (A1–C2; для этой книги ≈ B1/B2)
- Тематическая категория (`topic`) и подтема (`subtopic`)
- Стилистическая пометка (`note`, напр. «грубый оттенок») — если есть
- Пример употребления — если есть
- Синонимы / антонимы — если есть
- Колода (`deck`): в MVP только `words` (задел: phrasal / idioms)
- Озвучка 🔊 (Web Speech API, en-US/en-GB)

### 3.2. Экран «Словарь»

Каталог всех слов курса:
- **Фильтры:** по уровню, категории, статусу изучения (новые / в процессе /
  выученные / скрытые)
- **Сортировки:** по алфавиту, уровню, прогрессу, дате добавления
- **Поиск** по английскому слову и русскому переводу
- Раскрытие строки: перевод, пример, синонимы/антонимы, озвучка, SRS-индикатор
- Слово можно скрыть из тренировок или отправить учиться

### 3.3. Пользовательский контент

- Пользователь добавляет свои карточки (обязательны слово и перевод), может их
  редактировать/удалять; встроенные — скрывать.

### 3.4. Механика — интервальные повторения (Лейтнер)

- У пары «пользователь + карточка» — уровень 0–6 и дата следующего показа
- «Знаю» → уровень +1, интервалы: сразу → 1 → 2 → 4 → 7 → 15 → 30 дней
- «Не знаю» → уровень сбрасывается на 0
- Уровень 6 = «выучено»
- Если карточек «к повторению» меньше размера сессии — подмешиваются новые

### 3.5. Режимы тренировки (все три в MVP)

1. **Карточки** — EN → вспомнил → перевернул → «знаю / не знаю»
2. **Викторина** — правильный перевод из 4 вариантов, EN→RU и RU→EN чередуются
3. **Письмо** — по переводу напечатать слово (без учёта регистра; при ошибке
   показывается правильный ответ)

Результат ответа в любом режиме обновляет SRS-уровень карточки.

### 3.6. Сессия

- ~15 карточек, прогресс-бар
- Перед стартом можно ограничить: тема + уровень
- Экран результатов: «знаю» / «повторить», обновление стрика

## 4. Курс-грамматика (grammar)

### 4.1. Контент

Источник MVP: «Grammar Is All You Need 2.0»
(`docs/source/grammar-2.0.md`). Книга — 14 глав; **в MVP — первые 5 тем:**

1. Согласование подлежащего и сказуемого
2. Relative clauses и pronouns
3. Пассивный залог
4. Модальные глаголы
5. Инверсия

Каждая тема = **урок**. Пополнение (главы 6–14) — добавлением seed без изменения
кода.

### 4.2. Структура урока

- **Теория** — правило и примеры (Markdown, из книги)
- **Упражнения** — банк заготовленных заданий (в MVP ~10–15 на урок)
- **ИИ-экзамен по теме** — проверка усвоения (см. раздел 5)

### 4.3. Доступ и прохождение

- **Все уроки открыты сразу** (свободный доступ), пользователь выбирает сам.
- Урок имеет статус: `not_started` / `in_progress` / `passed`.
- Урок считается **пройденным (passed)**, когда сдан **ИИ-экзамен** по теме.
- **SRS для грамматики в MVP не применяется** (только у слов). Интервальное
  повторение грамматических тем — задел на будущее.

### 4.4. Типы упражнений

- **Автопроверяемые** (без ИИ): заполнение пропуска (`fill_blank`), выбор из
  вариантов (`multiple_choice`), сборка предложения (`reorder`) — сверка
  нормализованной строки/выбора.
- **Проверяемые ИИ**: перевод предложения (`translate`), исправление ошибок
  (`correct_error`) — вердикт выносит ИИ.

## 5. Проверка усвоения через ИИ

### 5.1. Роли ИИ

- **A. Проверка ответов** (MVP): для «свободных» упражнений ИИ оценивает ответ —
  верно/неверно, объясняет ошибку по-русски, даёт подсказку.
- **B. Экзамен по теме** (MVP): в конце урока ИИ по теории генерирует несколько
  вопросов, оценивает ответы и выносит вердикт «усвоено / повторить».
- **C. Репетитор-диалог** (после MVP): свободная практика по теме с исправлением
  ошибок вживую.
- **Адаптивность** (после MVP): заметив, что пользователь «плывёт» (серия
  ошибок), ИИ даёт упрощённое объяснение и генерирует дополнительные вопросы под
  слабое место.

### 5.2. Технические требования

- ИИ вызывается **только на сервере**; ключ API не покидает бэкенд.
- Провайдер — **Claude** (модель и стоимость фиксируются при реализации).
- Ответы ИИ — **структурированные** (валидируются Zod-схемами из
  `@wordforge/shared`).
- В тестах ИИ-клиент **мокается** — детерминизм, без реальных вызовов.

## 6. Архитектура и стек (утверждено)

| Слой | Технология |
|------|-----------|
| Монорепозиторий | pnpm workspaces + Turborepo (apps/client, apps/server, packages/shared) |
| Frontend | React 18 + Vite + TypeScript, архитектура **FEOD** |
| Состояние и логика | **MobX** — вся логика фронтенда (бизнес и UI) в сторах |
| Роутинг | TanStack Router (code-based) |
| Формы | React Hook Form (+ zodResolver) |
| UI | shadcn/ui + Tailwind CSS |
| Backend | Node.js + TypeScript + **Fastify** |
| База данных | **PostgreSQL** + **Drizzle ORM** (`pg-core`, драйвер postgres.js, миграции через drizzle-kit). Прод — managed Postgres (Neon); dev — docker-compose; тесты — PGlite |
| Валидация/контракт | **Zod** в `@wordforge/shared` — переиспользуется на фронте |
| Авторизация | email + пароль, bcrypt + JWT + stateful refresh (реализовано) |
| ИИ | **Claude** (Anthropic SDK), только на сервере |
| Озвучка | Web Speech API (браузерная, бесплатная) |

### 6.1. Модули (FEOD, клиент и сервер)

`Courses` (оболочка: витрина, запись, прогресс) · `Vocabulary` (SRS) ·
`Grammar` (уроки/упражнения) · `AI` (проверка/экзамен — только сервер) ·
`Stats` (дашборд/стрик) · `Auth` (реализовано).

### 6.2. Модель данных

Auth-таблицы (`users`, `refresh_tokens`) — без изменений. Новые:
`courses`, `enrollments`, `cards`, `card_progress`, `lessons`, `exercises`,
`exercise_attempts`, `lesson_progress` (+ опц. `exam_attempts`). Полная схема —
в дизайн-спеке, раздел 4.

### 6.3. API (все `/api/*`, кроме auth — требуют JWT)

```
GET  /api/courses                      курсы + прогресс
POST /api/courses/:slug/enroll         записаться
GET  /api/stats                        дашборд: по курсам, стрик, счётчики
--- vocabulary ---
GET  /api/courses/:slug/cards          словарь (?topic=&status=&search=&sort=&order=)
GET  /api/courses/:slug/session        SRS-сессия (?topic=&size=15)
POST /api/review                       {card_id, known} → SRS + стрик
--- grammar ---
GET  /api/courses/:slug/lessons        уроки + статусы
GET  /api/lessons/:id                  теория + упражнения
POST /api/lessons/:id/exercises/:eid/attempt   {answer} → {correct, feedback}
POST /api/lessons/:id/exam             ИИ-экзамен по теме
```

Ответы об ошибке — `{ message: string }` с русским текстом.

## 7. Нефункциональные требования

- Язык интерфейса — русский
- Адаптивная вёрстка, mobile-first (основной сценарий — телефон)
- Запуск для разработки: `pnpm dev` в корне (Turborepo поднимает клиент и сервер)
- Пароли не хранятся в открытом виде; секреты (JWT, ключ ИИ) — через env
- Тестирование — integration-first: `app.inject()` против **PGlite**
  (встроенный Postgres, свежая БД на тест-файл), ИИ-клиент замокан
- **Продакшен с самого начала:** код и инфраструктура пишутся под прод
  (managed Postgres, миграции на деплое, секреты через env)

## 8. Объём MVP

- **Оболочка:** витрина «Курсы», запись, прогресс по курсу, стрик, дашборд.
- **Курс-словарь:** весь контент (~3000 слов) как seed; SRS; 3 режима тренировки;
  экран «Словарь»; пользовательские карточки.
- **Курс-грамматика:** первые 5 тем (теория + банк упражнений + ИИ-экзамен);
  все уроки открыты; зачёт по ИИ-экзамену; без SRS.
- **ИИ:** роли A (проверка ответов) + B (экзамен по теме).

**Вне scope MVP:** ИИ-адаптивность, генерация упражнений на лету,
репетитор-диалог (C), колоды phrasal/idioms, транскрипция, график активности,
достижения, тёмная тема, экспорт/импорт, восстановление пароля. Модель данных и
код закладывают эти расширения, но не реализуют.

## 9. Фазы

**MVP (фаза 1):** разделы 2–8.

**Фаза 2:** ИИ-адаптивность и репетитор-диалог (C), генерация упражнений на лету,
SRS для грамматики, колоды phrasal/idioms, остальные главы грамматики (6–14),
транскрипция, график активности, достижения, тёмная тема, экспорт/импорт,
восстановление пароля.
