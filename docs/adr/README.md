# Architecture Decision Records (ADR)

Короткие записи ключевых архитектурных решений: **контекст → решение →
альтернативы → последствия**. Цель — фиксировать *почему*, а не только *что*,
и практиковать систем-дизайн (осознанные, обоснованные решения на текущем
масштабе, без карго-культа).

Формат (MADR-lite): статус, контекст, рассмотренные варианты, решение,
последствия. Номер — сквозной, файл — `NNNN-kebab-title.md`.
